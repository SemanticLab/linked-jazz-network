# Linked Jazz 2026 — People Network

Interactive network of ~70k people and their relationships, extracted from
1,300+ jazz oral-history interviews across four archives (Tulane's Hogan Jazz
Archive, Hamilton College's Fillius Jazz Archive, the Smithsonian Jazz Oral
History Program, Rutgers' Institute of Jazz Studies).
Live at **https://thisismattmiller.github.io/linked-jazz-2026-network/**

Fully static: raw Canvas 2D renderer (no libraries), Force Atlas 2 layout and
Louvain communities precomputed offline, portrait sprite atlas, and a lazy
per-pair evidence store (`site/ev/<xx>/<hash>.json`) so clicking a
relationship shows the actual transcript passages that produced it — with a
deep link into the companion
[transcript reader](https://github.com/thisismattmiller/linked-jazz-2026-transcripts)
to read the full interview.

## Updating the site

Everything in `site/` is generated by the (private) `ch-jazz-mashup` pipeline
repo (extraction → LLM name curation → layout → evidence store — see
`network/README.md` there). To update:

```bash
./sync.sh            # rsync ~/git/ch-jazz-mashup/network/web/ -> site/
# review, commit, push — the workflow publishes site/ to Pages
```

## Deploy

Pushing to `main` publishes `site/` via `.github/workflows/deploy.yml`
(one-time setup: repo Settings → Pages → Source = "GitHub Actions").
